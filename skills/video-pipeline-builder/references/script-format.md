# Script format

A script is plain text or Markdown. Scenes are separated by a `---` line; if none exists, by blank lines.

Inside a scene:
- First `# Heading` line = scene title (optional).
- `@key: value` lines = directives (optional):
  - `@duration: 5` seconds (otherwise estimated from word count at `--wpm`, min 2s, +1s padding)
  - `@bg: #0f172a` any CSS color (otherwise cycles a default palette)
  - `@image: img/photo.png` file under `public/`
  - `@audio: audio/scene-1.mp3` file under `public/` (voiceover; set `@duration` to match its length)
- Remaining lines = on-screen text / narration.

Notes:
- Referenced images/audio must be copied into `<out_dir>/public/` before rendering; the scaffold step warns about missing files.
- Narration audio is not generated by this skill. For TTS, generate files externally and reference them with `@audio`.
